# LessonStudio 0.1 Beta 1

Beta para avaliar gravação de aulas, tutoriais e vídeos explicativos no Mac.

## Download

Nos arquivos anexados a esta release:

- `LessonStudio-0.1-beta1-apple-silicon.dmg`: instalador para Macs com chip Apple.
- `LessonStudio-0.1-beta1-apple-silicon.dmg.sha256`: checksum do instalador.

Requer macOS 14 Sonoma ou mais recente. Não funciona em Macs Intel.

## Importante

Esta versão usa assinatura local de desenvolvimento. **Não está notarizada
pela Apple e pode ser bloqueada em outro Mac.** Não desative as proteções
do sistema. O pacote não inclui certificados para instalar.

Arraste o app para Aplicativos, ejete o DMG e abra a mesma instalação.
Autorize tela, câmera e microfone conforme os recursos usados. Se o macOS
solicitar que o app seja encerrado depois de autorizar, feche e reabra.

Confira a prévia antes de gravar. Durante a captura ela é ocultada para
reduzir o trabalho de exibição; os efeitos são aplicados ao vídeo gravado.

Os testes automáticos locais passaram, mas instalação e permissões em outro
Mac ainda não foram validadas. Comece com 20 segundos, reproduza e exporte.
Use as instruções e o roteiro de teste disponíveis no README do repositório.

Relate falhas em Issues sem anexar informações pessoais ou gravações privadas.
